# Upstream provenance

This file records the external sources used to build or document the core.
The repository contains no game ROM data.

## MiSTer framework

- Repository: `https://github.com/MiSTer-devel/Template_MiSTer.git`
- Base commit: `69b8a2acc6d84dd313b5abcba6a17155287ed3d8`
- License: GPL-3.0-or-later and per-file notices

The `sys/` directory is a vendored MiSTer framework snapshot. Individual
source headers retain their original copyright and license notices.

## fx68k processor core

- Repository: `https://github.com/jtfpga/fx68k.git`
- Upstream commit: `1217ab8dc600de070c6adb71ea6fe69de8855362`
- Local path: `rtl/fx68k`
- License: GPL-3.0

The bundled Verilator-compatible SystemVerilog variant is adapted locally for
the TMP68301 subsystem. Jorge Cwik's README and GPL license are retained.

## CRT geometry

## MAME hardware reference

- Repository: `https://github.com/mamedev/mame.git`
- MAME 0.287 tag commit: `e776c98438a465d3486c367cbad3777a6eb7902e`
- Driver: `src/mame/seta/seta2.cpp`
- Video device: `src/devices/video/x1_020_dx_101.cpp`
- Sound device: `src/devices/sound/x1_010.cpp`

MAME was used as public hardware documentation and a behavioral reference. No
MAME source code is copied into this core. Hardware addresses, ROM metadata,
timing behavior, and device semantics are interoperability facts independently
implemented in HDL and XML.

## MRA cheat engine

- Repository: `https://github.com/MiSTer-devel/Arcade-IremM92_MiSTer.git`
- Upstream commit inspected: `68a4683e237eafca02e3df56dd84bacc255fba55`
- Sources: `rtl/cheatengine.sv` and the code receiver in `rtl/m92.sv`
- Upstream author and copyright holder: Martin Donlon (2023)
- Original cheat-code handling: Kitrinx (2019)
- Upstream license: GPL-2.0-or-later
- Local path: `rtl/gd_mra_cheats.sv`

The engine retains the 16-byte Flags/Address/Compare/Data protocol and replaces
the M92 little-endian lanes with 68000 big-endian lanes. The local adaptation
uses eight slots, validates code flags, alignment, addresses and packet order,
and explicitly rejects longword comparison. It preserves the upstream
copyright/license notice and credits Kitrinx. MRA selection handling was also
checked against MiSTer Main's `cheats.cpp` and `support/arcade/mra_loader.cpp`.

## Direct DDR ROM loading

- Repository: `https://github.com/MiSTer-devel/Arcade-IGSPGM_MiSTer.git`
- Upstream commit inspected: `6f757e42779a93e940134018c25f08aafaf95b93`
- Source: `rtl/rom_loader.sv`, `ddr_rom_loader_adaptor` at line 202
- Upstream author and copyright holder: Martin Donlon
- Upstream license: GPL-3.0-or-later

`rtl/gd_ddr_rom_loader_adaptor.sv` adapts the direct-to-DDR staging and replay
approach to Gundam EX Revue's compact 22.5 MiB MRA stream. It adds an explicit
byte-address output, a continuous loader-reset handoff, end-of-image handling,
and arbitration with this core's packed runtime DDR client. Its original
copyright and GPL notice are retained in the source header and the author is
also credited in `CREDITS.md`.

## Related Guardians SDRAM regression

- Repository: `https://github.com/MiSTer-devel/Arcade-Guardians_MiSTer.git`
- Reference: `v1.4.1`, commit `8beb043209601ce69adf1358509fc854a24bd0ac`
- Source adapted: `sim/tb_gd_sdram_f0_rom.sv`
- Authors: OpenAI Codex and kandowontu
- License: GPL-3.0-or-later

The synthetic pin-storage regression was adapted to Gundam's unchanged
62.5 MHz inverted forwarded clock and its paired-edge test windows. The
production sampler follows Gundam's own private comparison experiment
(`2b835e6`, retained locally), not Guardians' different PLL configuration.
The audit checks the same fixed falling capture and rising-edge retimer
structure. No private overlay, font, CRC controller or edge selector is
included in the production project.

## Intel/Altera DDIO primitives

`gd_sdram.sv` instantiates ALTDDIO_OUT and ALTDDIO_IN through Quartus's FPGA
primitive interface. Vendor simulation libraries are not copied into this
repository. The generated FPGA IP described below retains its vendor terms.

## Generated FPGA IP terms

The PLL files below `rtl/pll*` and `sys/pll*` were generated by Intel/Altera
Quartus Prime and retain their generated notices. They are included solely to
reproduce the DE10-Nano build and remain subject to Intel's applicable FPGA IP
terms.
